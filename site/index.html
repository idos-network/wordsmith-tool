Wordsmith

Write in your language. Send in English.

A tiny macOS menu bar app. Select what you typed, tap ⌥ twice, pick Professional, Shorter or Casual, and proper English replaces it right where you wrote it.

Download for Mac macOS 13+ · Apple silicon · build __VERSION__

Two shortcuts, nothing else

⌥⌥

Rewrite

Three English versions of your selection: Professional, Shorter and Casual. Pick one with 1–4 or the arrows and it replaces your text in place. Your clipboard is put back.

⌃⌃

Summarize

The gist of a long thread or email: the bottom line plus the decisions, action items, deadlines and numbers. In English and in your system language, ready to copy.

No API key

Runs on your Claude subscription

Wordsmith calls the Claude Code CLI you are already signed in to. Nothing to configure, no key to paste.

Install

  1. Install Claude Code and sign in. Run claude auth login once in Terminal.
  2. Unzip and move Wordsmith to Applications.
  3. Open it once. The app is not notarized, so macOS blocks the first launch: open System Settings → Privacy & Security and click Open Anyway. Or run xattr -dr com.apple.quarantine /Applications/Wordsmith.app.
  4. Allow Accessibility when asked. Wordsmith needs it to copy your selection and paste the result.
  5. Using the Claude desktop app? It also listens for double ⌥. Turn that off in its settings.
